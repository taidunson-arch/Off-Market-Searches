# sample-output/ — worked example (Portland metro, affordable/regulated, 5-year horizon)

Everything in this folder except `run_config.example.json` is **generated by the scripts**; nothing was copied
from the improvised `Portland_Affordable_Maturity_Targets.xlsx` built earlier. Regenerate with:

```bash
python scripts/run_pipeline.py --config references/sample-output/run_config.example.json --as-of 2026-10-04
```

(The example config points `local_datasets` at the OHCS inventory CSV downloaded 2026-10-02; change the path to
your copy. `out_dir` is `runs/`; copy `runs/<as_of>/Portland_Affordable_TriCounty_5yr_Targets.xlsx` and `brief.md` here.)

## Why it has no RECORDED dates and no Tier A

The inventory publishes regulatory expirations (REPORTED) and a compliance start date (Year 15 is DERIVED), not loan
maturities; the only debt dates are the 15-year mini-perm estimates from `Financial_Closing_Date` (PROXY, +/-36 months,
0.30 multiplier), and most closings are 2014-2023 so just one of those falls inside the 5-year window. With only the
OHCS CSV, dates are REPORTED/DERIVED (one PROXY mini-perm inside the horizon). No lead reached above Tier C in this run
because the debt, declared-intent and operating families are absent, not because of the proxy-only cap: that cap
applies only to leads whose governing events are all PROXY, a REPORTED-only lead reached 42.5 (Tier C), and Tier B is
arithmetically reachable once a second family appears. The `Summary` tab and the brief say so ("Degraded run").

Files that add the missing families (drop them in the inbox and re-run):

1. **HUD Insured Multifamily Mortgages - Active (and Terminated)** -> RECORDED `LOAN_MATURITY` / `HUD_DIRECT_LOAN_MATURITY`, prepay windows, refinance suppression (`normalize_hud_insured.py`).
2. **HUD Multifamily Assistance & Section 8 Contracts** -> `HAP_EXPIRATION` with renewal pattern, owner / management-agent names (`normalize_hud_sec8.py`).
3. **OHCS 10-Year Expiration Forecast / PuSH dashboard export** -> `PRESERVATION_NOTICE_RECEIVED` (the strongest affordable signal, 20 points) and `on_state_expiring_list` (`normalize_ohcs_forecast.py`; field names unverified until the export is profiled).
4. **Recorder index export** for the Tier C leads -> ESTIMATED maturities from trust deeds, then RECORDED after buying the image (Multnomah fee per county snippet, unverified; `market-params.json`).
5. **HUD REAC/NSPIRE scores, assessor tax status** -> operating-distress family for stacking.
6. **Current MTSP max rents** pasted into `references/sources/oregon-portland/rent-limits.json` -> `restricted_income_proxy` replaces the `ppu_band` value shown here.

## Known data-quality notes reproduced in the sample

- `Financial_Closing_Date` is day-first (`%d/%m/%Y`): 222 of 298 values have a first field > 12. Every other slash column is month-first. `USDA_RD_Expiration_Date` is `%Y %b %d %I:%M:%S %p`.
- `Rehab Year` is stored as `2,021`-style text in 99 rows; the adapter strips the comma so the 2020-2022 rehabs receive the shared -15 penalty, and units are written as integers.
- `LATEST_Expiration_Date` is blank in 554 statewide rows and recomputed as max(components); `Casa Sonada 4` and `Riverside Terrace` (outside the metro) carry `Verify — Conflicting Sources` because LATEST != max(components).
- `City` typo `Portalnd` is corrected; `city_limits` mode therefore sees 518 rows (517 + 1), all graded `city_name_weak`.
- Phases listed at one address (Forest Manor I / II, Pines I / II, Yards at Union Station A / B) keep distinct `property_id`s with a `duplicate_address_in_inventory` signal.
- `Owner Type` is blank for 57% of rows; `owner_type` is inferred from name tokens (LP/LLC -> LIHTC partnership; nonprofit tokens; Housing Authority) and every decision maker is `not in public record` until the SOS worklist is resolved.
- `PRESERVATION_NOTICE_WINDOW` is emitted only for 5+ unit properties with a PuSH-covered program (ORS 456.250), with windows from OAR 813-115 snippets (statute text unverified).
- Every value is `ppu_band` (units x Kidder Q2 2026 average price per unit, verify) with `Missing Source — Request Document` for the rent roll; as-restricted value is usually lower.
