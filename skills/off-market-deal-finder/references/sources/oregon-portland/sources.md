# Source Directory: Portland, Oregon market pack

Every source the three class modules reference for this market, with access tier, cost where known, cadence, key fields and verification status. `verified_live` is `false` unless a researcher fetched the page or file directly; this build environment blocked every government and vendor host, so only the OHCS CSV on disk and the edgartools parser guide (GitHub raw) are `true`. `scripts/smoke_test_sources.py --pack references/sources/oregon-portland` re-checks every URL and writes `sources_status.json`; it never edits this file. Never construct a deep link that is not shown here; describe how to find it instead.

Adapters marked `future` are specified but not shipped in v2 scripts; drop the file in the inbox and the run manifest records it as unprocessed.
