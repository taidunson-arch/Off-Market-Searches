# Federal and National Tapes

Sources that apply to every US market. A market pack's `sources.md` repeats the rows it uses with any local notes (join keys, state filters). Column meanings and access tiers: `references/sources/README.md`. Every row is `verified_live=false` except the edgartools parser guide, because this build environment blocked all government and vendor hosts; fields and cadence were confirmed through search snippets, data.gov / openICPSR mirrors and prior knowledge. Re-verify headers before coding against them.
