# Federal and National Tapes and Rules

Sources and rules that apply to every US jurisdiction. A pack's `sources.md` repeats the rows it uses with any local notes (join keys, state filters). Column meanings and access tiers: `references/sources/README.md`. Every row is `verified_live=false`, because this build environment blocked all government and vendor hosts; fields and cadence were confirmed through search snippets, data.gov mirrors and prior knowledge. Re-verify headers before coding against them. Loan tapes for securitized market-rate debt (Ginnie Mae, DUS Disclose, Freddie MSIA, EDGAR EX-102, CMBS IRP) and every paid consolidator and skip-trace vendor from the buyer-side pack are removed: the agency's own ledger is its loan tape, and HUD FHASL supplies senior HUD maturities.
