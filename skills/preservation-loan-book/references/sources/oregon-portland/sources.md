# Source Directory: Portland, Oregon pack (preservation-loan-book)

Every source the module references for this market, with access tier, cost where known, cadence, key fields and verification status. `verified_live` is `false` unless a researcher fetched the page or file directly; this build environment blocked every government and vendor host, so only the OHCS CSV on disk is `true` (and the agency's own extract once supplied). `scripts/smoke_test_sources.py --pack references/sources/oregon-portland` re-checks every URL and writes `sources_status.json`; it never edits this file. Never construct a deep link that is not shown here; describe how to find it instead. The agency's own records come first; paid consolidators, skip-trace vendors, sheriff-sale monitors, trustee sites, DOR deferral, wholesaling and rent-cap sources from the buyer-side pack are removed.

Adapters marked `future` are specified but not shipped; drop the file in the inbox and the run manifest records it as unprocessed.
